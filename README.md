# Web Designing & Development (WDD) Practical Repository

## Project Overview
This repository contains a curated collection of **28 hands-on web application modules** created as part of the Web Designing and Development (WDD) practical coursework. Built with **HTML5**, **CSS3**, and **PHP**, the collection covers key web functionality—including registration workflows, online billing systems, interactive calculators, form validators, secure login gateways, booking portals, and academic result processing modules.

Each program highlights the integration of responsive frontend interfaces with efficient server-side processing to deliver smooth, user-friendly experiences.

---

## Key Highlights
- **28 Hands-on Projects:** A step-by-step practical series moving from structural markup to backend scripts.
- **Frontend Design:** Clean, semantic HTML5 structure styled with modular external CSS3.
- **Backend Execution:** PHP-driven server-side processing utilizing the HTTP `POST` method.
- **Data Integrity:** Dual-layer form validation to check user inputs before processing.
- **Custom Visual Themes:** Individually crafted color palettes and interface designs for every module.
- **Cross-Device Usability:** Mobile-friendly layouts built with responsive design patterns.

## Technical Competencies Demonstrated

Working through these 28 application modules highlights core competencies in:

- **HTML Form Architecture:** Crafting accessible forms, input field controls, and structured web layouts.
- **CSS Formatting:** Designing responsive grids, custom interface elements, and cross-browser styling.
- **PHP Form Handling:** Processing global request payloads (`$_POST`), sanitizing input values, and protecting data.
- **Validation Techniques:** Writing string manipulation functions, boundary checks, and custom validation logic.
- **Program Flow & Logic:** Implementing conditional branches (`if-else`, `switch`), loop execution, and custom reusable functions.
- **Dynamic Content Delivery:** Processing input on the server to output real-time computed HTML results.
